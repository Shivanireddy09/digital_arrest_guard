Digital Arrest Guard - run instructions
1. pip install -r requirements.txt
2. python test_engine.py            (checks the detection engine)
3. python guard_server.py           (starts the app at http://127.0.0.1:5000)
4. Register, login, scan messages. Switch language from the header.
5. Admin access: python guard_server.py makeadmin yourusername
Keep all .py files in the same folder.
