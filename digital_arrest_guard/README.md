
# Digital Arrest Guard

## Project Description
Digital Arrest Guard is a Python-based project designed to help identify and detect potential digital arrest scams.

## Objective
To create awareness about digital arrest scams and help users identify suspicious activities.

## Technologies Used
- Python
- Machine Learning (if implemented)
- Excel Dataset
- SQLite Database

## Project Features
- Scam detection
- Scam analysis
- Test engine
- Dataset evaluation

## Project Structure
- guard_server.py
- scam_engine.py
- lang_pack.py
- dataset_eval.py
- test_engine.py
- requirements.txt

## Installation

1. Clone the repository:

   git clone https://github.com/Shivanireddy09/digital_arrest_guard.git

2. Open the project folder.

3. Install dependencies:

   pip install -r requirements.txt

## How to Run

python guard_server.py
